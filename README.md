# ARVESSO

Modern restaurant website concept built around open-fire cooking, seasonal ingredients and contemporary Mediterranean-Caucasian flavors.

## Live Demo

https://setyann.github.io/ARVESSO/

## About

ARVESSO is a fictional restaurant network created as a commercial-style web development portfolio project.

The website includes:

- Responsive design
- Interactive menu filtering
- Multiple restaurant locations
- Signature dishes
- Image gallery
- Reviews carousel
- Reservation request form
- Responsive navigation
- Keyboard and touch interactions
- SEO metadata
- Accessibility-focused markup

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Font Awesome
- Google Fonts
